# Forte

Marketing site for Forte. The landing page lives in `src/app/(frontend)`.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Set `NEXT_PUBLIC_SERVER_URL` when you need a canonical origin for metadata, `robots.txt`, and the sitemap. See `.env.example`.

The Payload CMS app is on the `payload` branch.
